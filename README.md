# TrueExit Web

The web frontend for TrueExit.

TrueExit Web is a Progressive Web App (PWA) built with Astro, Svelte 5, and
TypeScript. It provides the web interface for the TrueExit platform.

## Technology Stack

| Technology      | Purpose                   |
| --------------- | ------------------------- |
| Astro           | Application framework     |
| Svelte 5        | Interactive UI components |
| TypeScript      | Static type checking      |
| Tailwind CSS v4 | Styling                   |
| shadcn-svelte   | UI component foundation   |
| Lucide          | Icons                     |
| Vitest          | Testing                   |
| ESLint          | Linting                   |
| Prettier        | Code formatting           |

## Prerequisites

Install the following before developing locally:

- **Node.js:** 22.12.0 or newer
- **npm:** Included with Node.js

## Getting Started
